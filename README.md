# Heartbeat – Audio Contributions

A snapshot of my contributions as Technical Sound Designer to the game project Heartbeat (First Impact Studios), 2024.

## My Role

Implementation of audio systems and SFX in collaboration with the development team, using Git/GitHub on the develop branch.


## Main Contributions (Feb - Jul 2024)

- Player ability audio (dash, recharge)
- UI SFX (MenuClose, PressPlay, SliderChange, Selection, ToggleOn/Off)
- Enemy SFX (EnemyDeath with pitch variations, EnemySpawn, EnemyAfterSpawn)
- Gameplay SFX (GameplayIntroduction, Beat, PlayerDeath, ScoreScreenEnter, KillchainDecrease)
- FMOD/Unity integration and sound API architecture

## Files

- AudioSoundAPI.cs - Main sound API implementation
- AudioListener.cs - Audio listener management
- AudioSettings.cs - Audio configuration
- Audio.asmdef - Assembly definition

The original team repository is no longer publicly accessible. This repository preserves a copy of my audio-related code contributions for portfolio purposes.
